# HASC Residential Reminder Portal

Standalone prototype for the Residential OneDrive directory and Microsoft Outlook sign-in testing.

No staff or resident records or Microsoft client secrets should be committed to this public repository.

Planned GitHub Pages URL: https://mshilcrat.github.io/hasc-reminder-portal/

Microsoft Entra SPA redirect URI must be configured to exactly match the hosted site URL before OAuth sign-in works.
